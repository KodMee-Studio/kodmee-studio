Über HandyTools

HandyTools vereint fünf praktische Alltagshelfer in einer einfachen, leicht zu bedienenden App. Vom Messen von Gegenständen und Prüfen der Ausrichtung über das Auswählen von Farben und Messen von Ringgrößen bis zur Kontrolle des Schallpegels – alles, was Sie brauchen, haben Sie immer dabei.

Wählen Sie Ihr Lieblingstool und behalten Sie es dauerhaft kostenlos. Möchten Sie alle fünf nutzen? Schalten Sie die übrigen jederzeit frei – mit einer Werbung für den Tag oder einem einmaligen Kauf.

Kein Durcheinander. Keine zusätzlichen Apps. Einfach fünf praktische Tools an einem Ort.

Häufig gestellte Fragen

Wie benutze ich die Tools?

Öffnen Sie ein beliebiges Tool und tippen Sie oben rechts auf das Symbol. Dort wird erklärt, was das Tool macht und wie Sie es verwenden.

Wie schalte ich die anderen Tools frei?

Beim Onboarding wählen Sie ein Tool aus, das dauerhaft kostenlos bleibt. Um die anderen Tools zu nutzen, schauen Sie sich entweder eine kurze Werbe-Belohnung an, um sie für den Tag freizuschalten, oder schalten Sie alle Tools dauerhaft über einen einmaligen In-App-Kauf frei.

Kann ich mein kostenloses Tool später ändern?

Ja. Gehen Sie zu den Einstellungen und schauen Sie sich eine Werbe-Belohnung an, um Ihr dauerhaft kostenloses Tool zu ändern.

Ich habe die Vollversion gekauft, aber sie wird auf diesem Gerät nicht angezeigt. Was soll ich tun?

Gehen Sie zu den Einstellungen und tippen Sie auf „Käufe wiederherstellen“. Falls das Problem weiterhin besteht, schreiben Sie uns unten mit Ihrer Apple-ID-E-Mail-Adresse, damit wir uns das ansehen können.

Warum sehe ich Werbung?

Werbung unterstützt die kostenlosen Tools in der App. Der Kauf der Vollversion entfernt Werbung und schaltet alle Tools dauerhaft frei.
